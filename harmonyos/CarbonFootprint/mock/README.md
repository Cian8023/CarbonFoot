# 城市碳普惠 Mock 服务

零依赖 Node 服务，用于演示 E3「碳普惠积分对接」。**不需要 `npm install`**，有 Node 就能跑。

## 一、启动

```bash
cd mock
node server.js          # 默认 8080
node server.js 9000     # 指定端口
```

启动后终端会打印监听地址和全部接口，`Ctrl+C` 停止。

## 二、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/benefits` | 返回权益列表 `{ code: 0, data: Benefit[] }` |
| POST | `/api/exchange` | 兑换权益，请求体 `{ "benefitId": "bus_2", "cost": 100 }` |
| GET | `/api/orders` | 最近 50 条兑换流水（内存态，重启清空） |
| GET | `/api/behavior` | 平台行程数据（模拟），供 App「从平台导入行为记录」使用 |
| GET | `/api/health` | 健康检查 |

`Benefit` 结构：`{ id, name, icon, cost, stock, desc }`

### `/api/behavior` 返回示例

```json
{"code":0,"simulated":true,"data":[
  {"type":"出行","subType":"地铁","value":12.6,"at":1793538025495,"label":"地铁行程"}
]}
```

App 在「我的 → 设置 → 服务配置 → 从平台导入行为记录」点「导入」，确认后写入 3 条出行记录，来源标记为 `platform`（导出 CSV 的「数据来源」段可见）。

> 时间戳以「今天零点」为基准固定，同一份数据每次请求都一样——App 侧按「类型|子类|时间」去重才有意义，重复导入不会翻倍。

**注意**：权益 `id` 前缀是 `bus_2` / `metro_50` 这类，与 App 内置模拟池的 `mock_bus` 等不同。看到 `bus_2` 就说明**已经连上远端**，不是降级模式。

## 三、让 App 连上

**正常情况下什么都不用填**：App 会按「用户配置 → `http://10.0.2.2:8080`（模拟器）→ `http://127.0.0.1:8080`」依次尝试，第一个通的就用。

手动配置（可选）：

1. 启动本服务，记下监听地址（如 `http://127.0.0.1:8080`）。
2. 打开 App →「我的」→「设置」→「服务配置」。
3. 在「碳普惠平台地址」填入地址，点「测试连接」（成功会提示「已连接城市碳普惠平台（地址）」）。
4. 返回「我的」→「城市碳普惠平台」，状态点应为**绿色**，权益 id 为 `bus_2` 这类（不是 `mock_*`）。

### 模拟器 / 真机的地址差异

| 场景 | 填什么 |
|---|---|
| **模拟器（默认自动命中）** | 不用填，自动试 `http://10.0.2.2:8080`（QEMU 固定的宿主机别名） |
| 真机与电脑同一 Wi-Fi | `http://<电脑局域网 IP>:8080`（如 `http://192.168.1.20:8080`） |
| 纯演示、不起服务 | 留空或填不可达地址 → 自动降级「内置模拟模式」，链路仍完整可演示 |

> ⚠️ **模拟器里的 `127.0.0.1` 指向模拟器自己，不是你的电脑**。模拟器是独立虚拟机，必须走 `10.0.2.2` 才能到宿主机。

> 应用已在 `resources/base/profile/network_config.json` 放开明文 HTTP，`http://` 不会被系统拦截。

## 四、验证命令（可选）

```bash
curl http://127.0.0.1:8080/api/benefits
curl -X POST http://127.0.0.1:8080/api/exchange \
     -H "Content-Type: application/json" \
     -d "{\"benefitId\":\"bus_2\",\"cost\":100}"
```

第二条应返回 `{"code":0,"message":"兑换成功",...}`，且 `stock` 减 1。

## 五、与 App 内置模拟池的关系

| 模式 | 触发条件 | 权益来源 | 库存 |
|---|---|---|---|
| 远端 | 地址可达且返回合法数据 | 本服务 | 服务端真实递减 |
| 内置模拟 | 地址为空 / 不可达 / 返回异常 | `InclusiveService.mockBenefits()` | 会话内内存递减 |

两种模式下**扣积分、写流水、权益入库**的本地记账逻辑完全一致，区别只在权益数据来源。
