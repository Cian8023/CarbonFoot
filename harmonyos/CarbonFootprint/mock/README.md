# 碳普惠平台 Mock 服务

配合应用「创新拓展 3 · 城市碳普惠」联调使用，模拟真实平台的权益与兑换接口。

## 启动

```bash
cd mock
node server.js        # 默认 8080 端口
node server.js 9000   # 指定端口
```

## 应用侧配置

1. 电脑与模拟器/真机同一局域网。
2. 应用内：我的 → 设置 → 服务配置 → 碳普惠平台地址，填 `http://<电脑局域网IP>:8080`。
3. 点「测试连接」，提示「已连接城市碳普惠平台」即打通；随后权益商城展示的是本服务的数据（兑换后库存实时递减）。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/benefits | 返回 `{code:200, data:[权益数组]}` |
| POST | /api/exchange | body `{benefitId, cost}`，成功 `{code:200}`，无库存 `{code:409}` |

> 模拟器访问电脑本机服务：Windows 侧 `127.0.0.1` 在模拟器中指向模拟器自身，需使用电脑局域网 IP（`ipconfig` 查看），或使用模拟器映射的 `10.0.2.2`（若模拟器支持）。
