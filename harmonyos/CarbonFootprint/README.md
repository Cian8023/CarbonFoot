# 碳足迹 · 全民绿色生活碳积分与减排指南

基于 HarmonyOS（ArkTS / ArkUI）开发的低碳生活记录应用（赛题二 · 全民绿色生活碳积分与减排指南）。

应用围绕"个人碳账户"实现低碳行为记录、减排量核算、碳积分激励、任务徽章体系、双碳科普五大核心功能，以及 AI 拍照识别、家庭碳账户、城市碳普惠对接、个性化智能推荐四大创新拓展（家庭多端同步当前为演示模式，详见"创新 1"）。

技术能力：`@ohos.data.relationalStore` 本地关系型数据库、Canvas 自绘图表（无三方图表依赖）、JSON/CSV 文件导出、OpenAI 兼容视觉接口调用。信息架构与 UI 设计范式参考华为运动健康 App（详见"七、设计对标"）。

## 一、核心功能

### 1. 低碳行为录入（录入页 / Record）
- 内置 4 大行为分类、19 个子类型，每个子类型带独立计量单位、单次录入上限与减排因子；分类与子类型选择器均为一行四列布局：

| 分类 | 子类型（单位） |
|------|----------------|
| 出行 | 步行(km)、骑行(km)、公交(km)、地铁(km)、拼车(km)、新能源车(km，相对燃油车基线的差额减排)、私家车(km，仅对比记录，不产生减排) |
| 节水节电 | 节水(L)、节电(kWh)、关空调(次) |
| 旧物回收 | 纸类(kg)、塑料(kg)、玻璃(kg)、衣物(kg)、电子(件)、厨余垃圾(kg) |
| 光盘行动 | 早餐(次)、午餐(次)、晚餐(次) |

- 录入校验：数值非负校验、按子类型单次上限校验，单位随子类型自动切换；
- 输入数值时实时显示预计减排量（kg CO₂e）与预计积分；
- 行为时间默认当前时刻，可补录今日内任意时刻，禁止选择未来时间；
- 备注长度 ≤ 100 字校验；
- 提交后 Toast 反馈（含本次减排量与积分），自动跳转至任务页，并在提交链路内完成任务达标评估与徽章检测（解锁时弹出全屏动画）。

### 2. 历史记录（历史页 / History）
- 双维度筛选：时间范围（全部 / 今日 / 近7天 / 近30天 / 自定义日期区间）× 行为分类（全部 / 出行 / 节水节电 / 旧物回收 / 光盘行动）；
- **关键字搜索**：按子类型名或备注模糊过滤，纯内存过滤不重复查库；
- **按日期分组显示**：列表按"今天 / 昨天 / M月D日"分节（跨年带年份），顶层分组采用 `LazyForEach` 懒加载渲染；
- 显示合计减排量、逐条记录明细，点击记录弹出详情面板：
  - 显示本笔记录关联的积分流水净额（发放 / 修改补正 / 冲减明细）；
  - 可**修改数值与日期**（事务内按积分差额自动补发或扣回流水，无需删除重录）；
  - 可修改备注；删除记录时在同一事务内写入负向积分流水对冲，保证减排量与积分账目一致（0 减排记录不产生冲减流水）；
- 附子类型减排对比条形图（当期口径）；
- 空数据时显示引导态，可一键跳转录入页。

### 3. 任务中心（任务页 / Tasks）
- 内置 12 个低碳任务（8 个每日任务 + 4 个每周任务），基于行为记录自动判定完成情况；周任务卡片显示"剩 N 天"倒计时；
- 支持两类判定口径：`sum`（按单位数值累加，且严格限定同单位子类型）与 `count`（按记录笔数）；
- 达标后自动发积分：评估挂在行为提交链路内（任务页刷新兜底），同一周期内只发一次，防止重复领取；
- **任务积分账目对称**：删除行为记录时在同一事务内重新核算相关任务进度，不再达标的任务自动撤销完成记录并扣回任务积分；
- **任务详情面板**：点击任务查看判定规则、剩余差距、本期贡献的具体行为记录（最多显示 20 笔）；
- 任务完成统计：本周完成次数、累计完成次数；
- 积分流水完整可查（来源 / 动作 / 增减 / 余额 / 时间），按来源筛选（低碳行为 / 任务奖励 / 阅读奖励 / 积分兑换），每页 50 条支持"加载更多"。

### 4. 徽章与证书（Badges）
- 内置 9 枚徽章：初次减碳、减排新兵(10kg)、绿色达人(50kg)、低碳先锋(100kg)、七日之约(连续7天)、坚持不懈(连续30天)、积分小能手(500积分)、任务达人(10次任务)、博学环保人(读10篇文章)；
- 徽章检测**三条路径全覆盖**：行为提交、任务发分、文章阅读后统一检测解锁（`checkAll` 幂等，调用方各检测一次，不会重复发动画）；
- 解锁时触发**全屏金色勋章动画**（弹性放大 + 光环扩散），三条路径解锁均生效；
- **徽章墙实时进度**：未解锁徽章显示进度条与量化进度（如 `3.2/10kg`、`4/7 天`），点击徽章弹出详情面板（解锁条件、当前进度、解锁时间）；
- 支持消耗 2000 积分兑换电子植树证书，通过安全控件保存到相册分享。

### 5. 双碳科普（Knowledge / KnowledgeDetail）
- 内置 **16 篇**科普文章，覆盖政策解读（4 篇）、生活技巧（5 篇）、行业动态（7 篇）三个栏目；
- 文章内容与行为体系刻意呼应，形成"读到 → 做到 → 记到"的内容闭环：

| 文章 | 对应的应用功能 |
|------|------|
| 自带杯与环保袋 | 碳普惠"自带杯咖啡券""环保帆布袋"权益场景 |
| 碳汇交易 | 植树证书积分兑换（云认养模式） |
| 个人碳账户 / 绿色金融 | 应用核心逻辑与碳普惠模块 |

- 完整阅读一篇文章奖励 5 积分（每篇仅奖励一次，需滚动至文末解锁领取）；
- 列表页显示阅读统计：已读篇数 / 总篇数 / 累计阅读积分，并提示徽章进度关联；
- 文章详情页提供"去记录低碳行为"入口，一键跳转录入页；
- 阅读路径解锁徽章时触发全屏动画（见第 4 节）。

### 6. 首页总览（Index）
- 今日减排大数字卡片、碳积分余额、待完成任务数、连续打卡天数（含"今日是否已打卡"状态点）；
- **本月减排目标环**（Canvas 圆环进度，实时计算达成率，达成后变金色；未达成时显示节奏提示"本月还剩 N 天，日均 X kg 即可达成"；目标值在「我的 → 设置」页顶部设置（首页"修改目标"直达））；
- **减排趋势柱状图**（日 / 周 / 月 / 年四档切换，对应近 7 天 / 8 周 / 12 月 / 5 年，当期柱高亮主绿并标注数值，柱多时仅标注峰值与当期防止拥挤，月份桶按真实日历回退不丢月）；
- **分类占比环形图**（中心大数字显示当期减排总量，带图例与百分比，无数据时显示空态而非空图）；
- **减排周报卡片**（本周减排、环比上周增减、本周打卡天数、最强子类型、鼓励语；**点击卡片直达历史页并预选"近7天"**）；
- 8 个快捷入口 + 智能推荐（个性化任务带推荐理由 + 生活建议）+ 待完成任务（带迷你进度线）；
- **首页卡片自定义排序与显隐**（「我的 → 设置 → 首页卡片布局」支持上移/下移/隐藏/显示，改动即时生效）。

### 7. 我的（Settings）
- 减排 / 碳积分余额 / 徽章 / **累计积分**（不含兑换扣减）四项统计 + 连续打卡天数；
- **设置中心独立成页**（pages/SettingsDetail，"我的 → 设置"进入）：个性化（本月减排目标、首页卡片布局排序/显隐）、服务配置（AI 接口地址/模型名/API Key、碳普惠平台地址 + 测试连接）、本地数据管理（备份/导入/CSV/清空）、关于，集中管理不再堆叠在"我的"页；
- **直达定位**：首页目标环的"修改目标"直接跳转设置页的目标设置区（该区位于页面顶部，即点即改）；
- **数据管理闭环**：JSON 一键备份（文件路径自动复制到剪贴板）、导入备份恢复（事务内原 ID 原样恢复，保证流水引用不断链）、月度减排 CSV 导出（UTF-8 BOM）、一键清空数据（二次确认）。

## 二、创新拓展功能

### 创新 1：家庭账户（Family / SyncService）
- 单设备创建家庭组生成邀请码，其他设备凭**邀请码 + 昵称**并入家庭成员（邀请码在演示模式下也有真实校验，不匹配无法并入）；
- 家庭合并减排、合并积分、成员排行链路完整可演示，成员数据由本机按昵称哈希稳定生成（同名成员数据一致，重演不穿帮）；
- `distributedDataObject` 真实多端同步为预留迭代方向（当前 `tryDistributedSync` 固定返回 false，页面文案如实标注演示模式）。

### 创新 2：AI 拍照识别录入（AiRecognize / AiRecognizeService）
- **拍照 / 相册双入口**：`cameraPicker` 拉起系统相机拍摄（安全 Picker，无需申请相机权限；模拟器使用内置虚拟相机画面，真机为真实拍摄），或从相册选图；
- 图片 → Base64 → 调用 OpenAI 兼容视觉接口（默认 DeepSeek，模型名可配置）→ 解析为行为字典匹配 → 预填录入表单一键录入；
- 未配置 API Key 或网络不可达时自动进入「离线演示识别」，按内置候选轮换返回，保证无网络也能演示完整链路。

### 创新 3：城市碳普惠平台对接（Inclusive / InclusiveService）
- 优先请求可配置地址的碳普惠平台 HTTP 接口获取可兑换权益（可配合本地 Node.js Mock 服务），「我的」页提供**测试连接**当场验证；
- 平台不可达时自动降级为内置 Mock 权益池；积分兑换权益走本地扣分 + 权益记录，**模拟权益库存随兑换递减、卖完显示"已兑完"**，兑换链路完整。

### 创新 4：个性化智能推荐（RecommendService）
- 规则引擎统计近 14 天各子类型频次与减排量；
- 高频强项 → 推荐加码挑战（保持习惯），低频弱项 → 推荐补短任务（引导养成）；
- 推荐任务附带**推荐理由**（如"近 14 天「骑行」12 次，是你的强项，加码正合适"/"近 14 天「回收」还是空白，从它开始补短"）；
- 输出排序后的推荐任务列表与生活建议，展示在首页。

### 服务层职责

| 服务 | 职责 |
|------|------|
| CalculationService | 加载因子库，按 `行为×数值×因子` 核算减排量；减排量→积分换算 |
| BehaviorService | 行为记录增删改查：提交（事务内写记录+积分流水，随后评估任务、检测徽章）、修改（事务内按积分差额补正流水）、删除（事务内冲减积分 + 回退不达标任务） |
| PointsService | 积分流水统一入口 `addPoints`（含来源/动作/增减/余额），余额查询、流水按来源筛选与限量分页、按引用反查本笔流水 |
| TaskService | 任务周期起点计算、进度判定（单位感知聚合）、达标自动发分（周期内幂等）、删除行为后回退不达标任务（撤销完成记录+扣分）、周完成统计 |
| BadgeService | 徽章解锁条件统一检测、连续打卡天数统计、徽章进度批量计算（聚合指标一次查询） |
| StatsService | 分类占比、日/周/月/年趋势分桶（真实日历回退，无丢月）、子类型对比、月度累计、减排周报 |
| KnowledgeService | 科普文章加载与已读奖励判定 |
| SeedService | 首次启动幂等预置任务/徽章定义（已存在则同步更新，便于种子修正生效） |
| ExportService | JSON 备份 / 导入恢复 / 月度 CSV 导出 / 清空数据 |
| SyncService | 家庭组创建/并入/退出、演示模式成员数据、家庭合并统计（真实多端同步为预留方向） |
| AiRecognizeService | 相机拍摄/相册选图、视觉接口调用、结果解析、离线演示识别 |
| InclusiveService | 碳普惠权益拉取（远程优先/本地 Mock 降级）、积分兑换与权益记录、模拟库存管理 |
| RecommendService | 基于近 14 天行为的强项/弱项规则引擎，带理由的任务推荐与生活建议 |

### 数据库表（关系型数据库，本机沙箱）

首次启动自动建 5 张表 + 2 个索引（`idx_behavior_time`、`idx_points_time`），并幂等预置任务/徽章数据：

| 表 | 用途 |
|----|------|
| t_behavior_record | 低碳行为记录（类型/子类型/数值/单位/因子/减排克数/时间/备注，因子冗余存入便于追溯） |
| t_points_record | 积分流水（来源/引用ID/动作/增减分/变动后余额/时间） |
| t_task | 任务定义（编码/标题/周期/积分/判定规则 JSON，在 PRD 基础上扩展 `check_json` 列） |
| t_task_completion | 任务完成记录（周期幂等发分的依据） |
| t_badge | 徽章定义与解锁状态（含 `description` 列） |

### 内置数据包（resources/rawfile）

| 文件 | 内容 |
|------|------|
| factors.json | 行为因子库：4 大类 19 子类型，含单位、每单位减排克数、单次上限、核算口径说明 |
| tasks.json | 12 个每日/每周任务定义（含判定规则） |
| badges.json | 9 枚徽章定义（解锁条件类型与阈值） |
| knowledge.json | 16 篇双碳科普文章（政策解读 4 / 生活技巧 5 / 行业动态 7，含摘要与正文段落） |

### 关键核算与一致性规则

| 规则 | 说明 |
|------|------|
| 减排量 | `数值 × 因子(g/单位)`，因子冗余存入行为记录 |
| 行为积分 | `max(1, 减排克数 / 100)`，即不足 100g 按 1 分起记；私家车等 0 减排行为不计分 |
| 阅读积分 | 每篇 5 分，一次性 |
| 证书兑换 | 2000 积分，扣减记入 `exchange` 流水 |
| 任务判定 | 同任务内只聚合相同单位的子类型，避免"次"与"度/kg"混算 |
| 账目一致 | 行为与积分的每一次增删改都在同一事务内完成并互相冲正：删除行为 → 冲减行为积分 + 回退不达标任务（撤销完成并扣分）；修改行为 → 按差额补发/扣回；积分发放以流水表存在性做幂等 |
| 页面刷新 | 数据变更后通过 `AppStorage('tick')` 全局事件广播，各页面 `@Watch` 自动刷新；跨页跳转传参（如周报卡预选历史页时间档）通过 `AppStorage` 键广播 |

### 权限与隐私设计

应用遵循**最小权限 + 数据本地化**原则：

| 设计点 | 说明 |
|------|------|
| 权限清单 | 仅声明 `ohos.permission.INTERNET` 一项 |
| 相机零权限 | 拍照使用 `cameraPicker` 系统 Picker（安全组件模式），拍摄发生在系统界面内，应用自身无需 CAMERA 权限即可获取拍摄结果 |
| 相册写入零权限 | 证书/海报保存使用 `SaveButton` 安全控件，点击时获得系统临时授权写入媒体库，无需申请写媒体库权限 |
| 文件选择零权限 | 备份导入使用 `DocumentViewPicker` 系统 Picker |
| 数据本地化 | 行为、积分、任务、徽章全部存储在本机沙箱 RDB，不上传任何服务器 |
| 上传范围说明 | 唯一的网络数据出口：① 用户主动配置 AI 服务后，所选拍照图片发送至用户配置的识别接口；② 用户主动配置碳普惠平台后，权益拉取与兑换请求发送至该地址。两个出口均默认关闭、地址均由用户掌控 |

### 可靠性设计

| 设计点 | 说明 |
|------|------|
| 事务冲正 | 行为提交（记录+流水）、行为修改（差额补正）、行为删除（冲减+任务回退）均使用 `beginTransaction / commit / rollback`；任何一步失败整体回滚 |
| 幂等发放 | 任务积分以 `t_task_completion` 周期记录幂等；阅读奖励以流水存在性幂等；证书兑换以偏好存储幂等——同场景不会重复发分 |
| 降级容错 | 三个联网能力均有完整兜底：AI 未配置/不可达 → 离线演示识别；碳普惠不可达 → 内置模拟权益池；分布式未组网 → 家庭演示模式。全部链路无网可演示 |
| 日期边界 | 月/年趋势桶使用真实日历回退（不丢 2 月）；周起始统一走 `startOfWeek`；禁止未来时间录入 |
| 空态覆盖 | 首页/历史/任务/流水等全部列表均有空态引导，无裸空白 |
| 渲染正确性 | 列表 key 设计包含状态与内容（如 `id + note + value`），状态变更可靠触发重渲染；长列表顶层 `LazyForEach` 懒加载 |

> 因子取值参考《省级温室气体清单编制指南》、GB/T 32150、公共交通人均排放公开口径等资料整理，作为生活场景估算的演示口径；对核算精度有更高要求的场景可替换为官方发布的本地化因子。

## 四、构建与运行

### 环境要求
- DevEco Studio（需能提供 HarmonyOS SDK 26.0.0，与工程 `build-profile.json5` 中声明的 compileSdkVersion 一致）
- HarmonyOS 模拟器或真机。**模拟器即可完整演示**：模拟器内置虚拟相机（拍照识别流程可用，识别不出自动落离线演示识别）、SaveButton 存相册、分布式演示模式均已适配模拟器
- 运行环境建议：Windows 10/11 64 位，内存 16GB 及以上，磁盘预留 30GB 以上可用空间

### 步骤
1. 安装 DevEco Studio 并在 SDK Manager 中安装 HarmonyOS SDK 26.0.0；
2. `File > Open` 打开项目根目录 `CarbonFootprint`，等待 IDE Sync 完成（零三方依赖，无需额外安装）；
3. **Build → Build Hap(s)/APP(s) → Build Hap(s)** 编译；
4. 通过 Device Manager 启动模拟器，点击 Run 安装启动（首次启动自动建表并预置任务、徽章数据，因子库与科普文章从 `resources/rawfile/*.json` 加载）；
5. 命令行部署（可选）：
   ```bash
   hdc file send 本机hap路径 /data/local/tmp/entry.hap
   hdc shell bm install -p /data/local/tmp
   hdc shell aa start -a EntryAbility -b com.carbon.footprint
   ```

### 演示数据准备
- 建议演示前提前录入 3~5 天分散数据（每天 2~3 笔不同分类），使周报环比、徽章进度、趋势柱状图在首屏即有内容；
- 也可以在演示机上先录入满意的数据后使用「我的 → 一键备份」导出 JSON；如需重置现场，先「清空所有数据」再「导入备份」即可秒级恢复到预演状态。

### 可选服务配置（「我的 → 服务配置」）
- **AI 识别**：填入 OpenAI 兼容接口地址（默认 DeepSeek `https://api.deepseek.com/v1/chat/completions`）、模型名与 API Key；留空则使用离线演示识别；
- **碳普惠平台**：填入平台地址（可用 Node.js 起本地 Mock 服务），可用「测试连接」当场验证；未连通时自动使用内置模拟权益池。

## 七、设计对标：华为运动健康

本项目在信息架构、交互范式与视觉语言上参考了华为运动健康 App 的成熟设计模式，将其"记录 → 可视化 → 目标打卡 → 激励 → 分享"的行为闭环迁移到低碳减排场景。

### 华为运动健康功能全景

- **底部四大 Tab**：首页（健康总览）/ 运动 / 设备 / 我的；
- **首页**：步数三环目标 + 卡片流（活动记录、睡眠、心率、压力、血氧、体重、饮水、健康计划等），卡片支持长按调整顺序；每日运动打卡记录（步数、活动热量、锻炼时长、运动距离）；
- **运动**：80+ 运动模式（户外跑步、骑行、游泳、跳绳等）、训练课程与智能训练计划、运动记录详情（轨迹、分段配速、心率区间）、自动打卡路线提醒；
- **健康研究**：与专业医疗机构合作的心脏健康研究（房颤/早搏风险筛查）、睡眠呼吸暂停筛查、血压管理（监测提醒、每日打卡、管理周报）；
- **家庭空间**：远程关注家人健康数据；
- **我的**：目标设置、数据卡片管理、成就勋章、运动周报月报。

### UI 设计借鉴点（本项目已落地）

| 华为运动健康的设计模式 | 本项目对应实现 |
|------|------|
| 绿色主色调 + 白卡圆角 + 卡片化信息分层 | 主绿 `#00B96B`、白卡 16px 圆角、扁平细边框卡片分区 |
| 底部 Tab 导航 + 大数字突出核心指标 | 5 Tab 导航；首页"今日减排"大数字卡片 + 积分/待完成/连续打卡 |
| 步数三环目标（圆环进度） | **本月减排目标环**（Canvas 圆环进度，达成率实时计算，达成变金色） |
| 周月年数据图表切换（柱状图） | **减排趋势柱状图**日 / 周 / 月 / 年四档切换（对应近 7 天 / 8 周 / 12 月 / 5 年），当期柱高亮并标注数值 |
| 每日打卡与连续激励 | 连续打卡天数统计 + "七日之约""坚持不懈"连续打卡徽章 |
| 目标 - 达成 - 奖励闭环 | 12 个低碳任务自动判定 → 碳积分 → 9 枚徽章 → 权益兑换 |
| 首页卡片自定义排序 | **我的 → 个性化 → 首页卡片布局**：7 张卡片上移/下移/隐藏/显示 |
| 成就勋章的仪式感 | **勋章解锁全屏金色动画**（弹性放大 + 光环扩散） |
| 卡片流"从细节到宏观"的信息层级 | 今日卡片 → 目标环 → 趋势柱状 → 分类占比 → 减排周报 → 推荐 → 待办 |
| 数据周报 | **减排周报卡片**（本周减排 / 环比上周 / 打卡天数 / 最强子类型 / 鼓励语） |
| 家庭空间（远程关注家人数据） | 家庭碳账户（合并减排 / 合并积分 / 成员排行，演示模式） |

### 功能定位差异

- 华为运动健康聚焦**个人健康数据监测与运动激励**，数据主要来自穿戴设备传感器（心率、血氧、睡眠等）；
- 本项目聚焦**低碳行为记录与碳积分激励**，数据来自用户录入与 AI 拍照识别，减排量按内置因子库核算；
- 两者共享同一行为闭环设计范式：**记录 → 可视化 → 目标打卡 → 激励 → 分享**。

### 借鉴落地情况与后续迭代方向

本轮借鉴已落地：**本月减排目标环**（对应步数圆环）、**减排趋势柱状图**（对应周活动柱状图）、**减排周报**（对应运动周报）、**勋章解锁动画**（对应成就仪式感）、**首页卡片排序与显隐**（对应运动健康首页卡片排序，拖拽简化为上移/下移按钮）。

后续迭代方向：
- 目标环升级为"今日 / 本周 / 本月"三环（对应运动健康三环）；
- 减排月报自动生成；
- 勋章收集进度动画与勋章墙样式增强。
