# 碳足迹 · 演示视频脚本

> 目标：5 分钟内用**真实操作**走完「记录 → 计算 → 统计 → 领积分 → AI 识别 → 多端同步 → 导出」闭环。
> 设备：OpenHarmony Phone 模拟器 127.0.0.1:5555，API 26，1440×2832（密度 3.5）。
> 约束：≤5 分钟、≤100 MB、全程匿名（不出现学校 / 团队 / 指导教师）。

---

## 一、录屏前准备（务必先做完）

### 1. 环境

| 项 | 做法 |
|---|---|
| 录屏工具 | 模拟器自带录屏，或 `scrcpy --record demo.mp4`（码率可控） |
| 关掉无关程序 | DevEco 可关（模拟器独立进程），减少卡顿 |
| 通知 | 打开系统「勿扰模式」，避免横幅入镜 |
| 字体 | 系统字体保持「标准」，不要放大 |

### 2. 数据（决定视频好不好看）

演示前构造「有起伏」的历史数据，否则趋势图只有一根柱子。

**推荐做法：用 AI 批量识别造数据（最快）**

1. 先在模拟器浏览器存 3~5 张票据图（地铁行程单 / 电费单 / 外卖单）：长按图片 → 「下载」
2. App → 首页「拍照识别」→ 相册选图 → 一次选 3~5 张 → 识别 → 全部录入
3. 再手动补 2 条往期记录（用「行为时间 → 修改」选日期）

**两条必做前提**：

- **先清空旧数据**：设置 → 本地数据管理 → 「清空所有数据」（二次确认）。
  > 必须清空：早期版本积分流水写「减排1080g」，现在统一成「减排1.08kg」。不清空会出现新旧两种单位同屏。
- **今日留少量或留空**，这样演示时新录 6 km 骑行，数字变化才明显（如 0.68 → 1.76）。

### 3. 服务（按镜头需要）

| 服务 | 命令 | 用途 |
|---|---|---|
| 家庭同步 | `node sync/server.js 8081` | 镜头 7 必需 |
| 碳普惠 Mock | `node mock/server.js 8080` | 仅在拍 E3 兑换时需要（本脚本不拍） |

### 4. 第二台设备（镜头 7 用）

```bash
# DevEco Device Manager 启动第二个 Phone 实例，端口通常为 5557
hdc list targets          # 应看到 5555 和 5557
```

两台设备都装同一个包，都连宿主机的 8081 服务，用同一组号加入。

> 只有一台设备时：镜头 7 降级为「只展示家庭页 + 口播说明两台已实测」，见第六节。

### 5. 演示前 30 秒自检

- [ ] App 冷启动一次，首页正常显示
- [ ] 积分余额 ≥ 100
- [ ] 趋势图有 5 根以上柱子
- [ ] 相册里有 ≥3 张可识别的票据图
- [ ] 录屏软件已开，画面无黑边

## 二、分镜脚本（总 4:45）

### 镜头 1｜开场 · 首页全景（0:00–0:20）

**操作**：停在首页，不滚动。

**画面**：今日减排大数字、目标环、连续打卡 / 碳积分 / 待办、8 个快捷入口。

**旁白**：
> 这是一个把日常低碳行为记成「碳账本」的鸿蒙应用。首页一眼能看到四件事：今天减排多少、本月目标完成多少、连续坚持几天、手里有多少碳积分。

---

### 镜头 2｜录入一条行为（0:20–1:05）

**操作**：
1. 点首页「行为录入」→ 切到录入页
2. 点子类型「骑行」
3. 点输入框 → 输入 `6` → 点键盘右上「∨」收键盘
4. 停留 2 秒（看清 1.080 kg / +10 积分）
5. 点底部「提交记录」

**画面重点**：输入瞬间实时刷新；卡片底部「按 180 g/km 系数估算，结果为估算值」。

**旁白**：
> 记一笔不超过 15 秒。选大类、选子类型、输数值，减排量实时算出来。骑行按每公里 180 克二氧化碳当量算，6 公里就是 1.08 公斤。输入的时候就知道能拿多少积分。因子出处和「这是估算值」的说明，界面上都有标注。

---

### 镜头 3｜积分双发放 + 任务规则（1:05–1:35）

**操作**：提交后 App 自动跳「任务 → 积分流水」，停住不动；再点上方「低碳任务」段。

**画面重点**：
- Toast「记录成功！减排 1.08 kg，+10 积分」
- 流水两条：`完成任务：骑行 5 公里 +10`、`骑行 6km，减排1.08kg +10`
- 任务页：本周完成数、进度条、规则说明

**旁白**：
> 提交后不用手动领奖。这一笔同时触发两件事：行为给 10 积分，「每日骑行 5 公里」任务达标再给 10 积分。每笔积分都记了来源、动作、余额和时间。任务是自动判定的，规则也写清楚了：每天零点重置，同一任务每期只发一次，重复记录不重复加分。

---

### 镜头 4｜看板联动（1:35–2:05）

**操作**：
1. 点「首页」
2. 停留看数字（今日 0.68 → 1.76、目标 37% → 40%）
3. 下滑到趋势图 → 点峰值柱 → 再点取消

**旁白**：
> 回到首页，今天从 0.68 涨到 1.76，本月完成度从 37% 走到 40%。趋势图支持日、周、月、年四档，柱状和折线两种形态，点任意一根柱子能看到那天的具体数值。

---

### 镜头 5｜历史与算法透明（2:05–2:40）

**操作**：
1. 点「历史」→ 点「今日」筛选
2. 点刚录的「骑行 6km」→ 详情弹层

**画面重点**：灰底说明块四行（计算式 / 口径 / 系数出处 / 免责声明）、「本笔积分 +10 分」。

**旁白**：
> 历史记录可以按时间、类别、关键字查。点开任意一条，能看到这笔减排怎么算的：6 公里乘每公里 180 克，等于 1.08 公斤。下面写了这个「1 公里」指什么、系数从哪来、哪一年整理的，还有一句「这是估算值，不用于碳交易或认证」。

---

### 镜头 6｜AI 批量识别（2:40–3:25）★ 加分项

**操作**：
1. 返回 → 首页点「拍照识别」→ 进 AI 页
2. 点「相册选图（可多选）」
3. 在相册里选 **3 张**（地铁行程单 / 电费账单 / 外卖订单）
   - 点图片 → 点右下角圆圈选中 → 再点下一张
4. 点「完成」
5. **不要动**，让进度走完（约 10~15 秒），按钮下方显示「正在识别 1/3 → 2/3 → 3/3」
6. 批量确认卡出现：3 条记录 + 合计 kg + 合计积分
7. 点「全部录入」

**画面重点**：识别进度、批量卡里每条的「行为 · 预计 xx kg」和可改数值、底部合计与「全部录入」。

**旁白**：
> 不想手输的时候可以拍照识别。一次最多选 9 张，行程单、电费单、外卖单都行。
> 识别时逐张显示进度，不会让你干等。识别出来是逐条的：地铁 12.6 公里、用电 128 度、光盘一次，数值取自票据原文，不是猜的。
> 每条都能改，确认无误再一次性录入。识别结果不会自动入库，一定要你点「全部录入」。

---

### 镜头 7｜家庭多端同步（3:25–3:50）★ 加分项

**操作**（双设备）：
1. 设备 A：我的 → 家庭碳账户 → 显示组号与成员
2. 设备 B 做一次录入（或已录入）
3. 设备 A 点「立即同步」→ 成员数据更新

**操作**（单设备降级）：
1. 我的 → 家庭碳账户 → 展示成员列表与排行
2. 口播说明两台设备实测

**画面重点**：组号、成员列表（各自减排 / 积分 / 本周）、排行。

**旁白**：
> 家庭账户让一家人各自记录、合并看。两台设备用同一个组号，各自上报减排和积分，服务端合并后显示排行。数据只在局域网内的服务里中转，不经过公网。服务不可达时会自动降级到本地缓存，不会白屏。

---

### 镜头 8｜科普专栏（3:50–4:05）

**操作**：我的 → 双碳科普 → 点第一篇 → 滚两下 → 返回。

**旁白**：
> 科普专栏内置 16 篇离线文章，政策解读、生活技巧、行业动态三类，读完能拿积分。

---

### 镜头 9｜数据备份与导出（4:05–4:30）

**操作**：
1. 我的 → 下滑点「设置」→ 滚到「本地数据管理」
2. 点「一键备份（JSON）」→ 系统文件选择器（文件名已填好）→ 右上角 ✓ 保存
3. Toast 显示实际文件名

**画面重点**：选择器里的文件名与可选目录、Toast 文案。

**旁白**：
> 数据全在手机本地，不上传云端。备份走系统文件选择器，存哪个目录你决定，保存完会提示文件名，在「文件管理」里能找到。除了 JSON 备份，还能导出 CSV 报表。

---

### 镜头 10｜收尾（4:30–4:45）

**操作**：回到「我的」页顶部，停在数据汇总卡。

**旁白**：
> 记录、核算、看板、积分、AI 识别、家庭同步、数据导出，形成闭环。全部基于 OpenHarmony API 12 以上开发，不依赖第三方库，本地离线可用。碳足迹，让每一笔低碳行为都有据可查。

## 四、自动化操作序列（给执行端）

> 坐标基于 1440×2832。**每次操作前建议先 dump 布局确认**，滚动位置变化后坐标会偏。

```bash
HDC="D:/aaaa/SDK/26.0.0/toolchains/hdc.exe"
T="-t 127.0.0.1:5555"

# 冷启动
$HDC $T shell aa force-stop com.carbon.footprint
$HDC $T shell aa start -a EntryAbility -b com.carbon.footprint
sleep 6

# 镜头2：录入骑行 6km
$HDC $T shell "uitest uiInput click 210 1626"     # 首页「行为录入」
sleep 2
$HDC $T shell "uitest uiInput click 555 718"      # 子类型「骑行」
sleep 1
$HDC $T shell "uitest uiInput click 632 1326"     # 聚焦输入框
sleep 1
$HDC $T shell "uitest uiInput inputText 632 1326 6"   # 输入 6（必须带坐标）
sleep 2
$HDC $T shell "uitest uiInput click 1325 1818"    # 收键盘
sleep 2
$HDC $T shell "uitest uiInput click 720 2391"     # 提交记录
sleep 3

# 镜头3：切「低碳任务」段
$HDC $T shell "uitest uiInput click 210 722"
sleep 2

# 镜头4：回首页 + 点峰值柱
$HDC $T shell "uitest uiInput click 105 2665"
sleep 2
$HDC $T shell "uitest uiInput swipe 700 2200 700 900 900"
sleep 2
$HDC $T shell "uitest uiInput click 1037 1800"    # 点峰值（11.2）
sleep 2
$HDC $T shell "uitest uiInput click 1037 1800"    # 取消
sleep 1

# 镜头5：历史 + 详情
$HDC $T shell "uitest uiInput click 720 2665"
sleep 2
$HDC $T shell "uitest uiInput click 600 1068"     # 第一条记录
sleep 2
$HDC $T shell "uitest uiInput click 1400 618"     # 关详情
sleep 1

# 镜头6：AI 批量识别
$HDC $T shell "uitest uiInput click 105 2665"     # 回首页
sleep 1
$HDC $T shell "uitest uiInput click 210 1900"     # 「拍照识别」
sleep 3
$HDC $T shell "uitest uiInput click 1065 1012"    # 「相册选图（可多选）」
sleep 4
# 相册内：点图 → 点右下角圆圈选中 → 重复 3 次
# 网格坐标随相册布局变化，务必 dump 后按图片位置点击
$HDC $T shell "uitest uiInput click 470 1080"     # 第 1 张（进入预览）
sleep 1
$HDC $T shell "uitest uiInput click 1320 1989"    # 选中圆圈
sleep 1
$HDC $T shell "uitest uiInput click 1257 2538"    # 「完成」
sleep 18                                          # 等 3 张识别完（每张 4~6 秒）

# 镜头7：家庭（双设备时切到设备 A）
$HDC $T shell "uitest uiInput click 1290 2665"    # 我的
sleep 2
# 「家庭碳账户」位置需 dump 确认（在「创新拓展」区）
```

### 已知易错点

| 坑 | 说明 |
|---|---|
| `inputText` 必须带坐标 | 只传文字无效，必须先 `click` 聚焦再 `inputText x y 值` |
| 键盘遮挡 | 输入后点键盘工具栏右侧 `∨`（约 1325,1818）收键盘 |
| 提交按钮 | 已固定底部，正常 y≈2390 |
| 首页快捷入口两行 | 第一行 y≈1626，第二行 y≈1900 |
| 相册多选 | 点图是**预览**，要点右下角圆圈才是**选中**；底部显示「已选 x/9」 |
| 批量识别耗时 | 每张 4~6 秒，9 张约 40~50 秒，期间显示「正在识别 n/9」 |
| 设置页备份按钮 | 强依赖滚动位置，先滑两次到底再 dump（实测 y≈1499） |
| 模拟器无相机 | 「拍照识别」在模拟器上必然失败（未安装相机应用），演示统一走「相册选图」 |
| 浏览器存图 | 下载的图不会自动进媒体库，相册选不到；需用 App 自己的「保存海报」或系统「保存图片」 |

## 六、兜底方案

| 突发 | 处理 |
|---|---|
| 只有一台设备 | 镜头 7 降级：只展示家庭页，口播说明「两台设备已实测，这里展示合并结果」 |
| 相册没有票据图 | 提前用浏览器存 3 张；实在没有就跳过镜头 6，用「普通照片 → 没看出低碳行为 → 手动录入」演示失败兜底 |
| AI 识别超时/失败 | 不剪掉，正好展示「如实报错 + 重试 + 去手动录入」，这是加分点 |
| 提交后没跳转 | 手动点「任务」tab，效果一样 |
| 录屏卡顿 | scrcpy 码率降到 4 Mbps，或改用模拟器自带录屏 |
| 时间不够 | 先砍镜头 8（科普），再砍镜头 9 的 CSV 部分 |

## 七、成片参数

| 项 | 目标 |
|---|---|
| 时长 | 4:40–5:00 |
| 分辨率 | 1080×2340 或原始 1440×2832 缩放 |
| 码率 | 4–6 Mbps（成片 ≤80 MB，留余量） |
| 音频 | 旁白 + 轻背景音乐（-20dB），音乐不盖人声 |
| 字幕 | 建议加，关键数字（1.08 kg、+10 积分、9 张）标出来 |
| 文件名 | `碳足迹-演示视频.mp4`（不含学校/团队名） |
