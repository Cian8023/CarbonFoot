## 1. 引言

### 1.1 编写目的
本文档为「碳足迹」应用的企业级测试完整方案，覆盖测试计划、测试策略、测试用例、缺陷管理与测试报告模板，指导测试人员按企业规范完成全量测试并出具可追溯的测试结论。

### 1.2 测试范围
**范围内**：五大主功能（F1 低碳行为核算、F2 数据可视化看板、F3 碳积分激励、F4 双碳科普、F5 本地数据管理）与四项创新拓展（E1 家庭多端演示、E2 AI 拍照识别、E3 碳普惠对接、E4 成果分享）的全部页面、服务、数据库与配置。
**范围外**：真实多端分布式同步（演示模式固定）、真实碳普惠生产接口（仅 Mock/可配置地址）、应用市场合规上架扫描。

## 6. 灰盒数据一致性专项（DB 校验）

执行方式：每步操作后用「设置 > 一键备份」导出 JSON 人工核对，或 hvigor 调试日志。

| 编号 | 校验点 | 通过标准 |
|---|---|---|
| DC-01 | behavior ↔ points 对称 | 每条 source=behavior 流水 ref_id 指向存在的行为 id（删除后保留冲减链） |
| DC-02 | 余额链 | 按 id 升序逐条 balance_after 差值 = points |
| DC-03 | 任务完成 ↔ 积分 | 每条 t_task_completion 周期内恰好对应一条 source=task 正向流水（撤销后两者同消） |
| DC-04 | 徽章解锁一次性 | unlocked=1 的徽章 unlock 动作历史（checkAll 幂等） |
| DC-05 | 导入闭合 | 备份→清空→导入 后 DC-01/02 全部成立 |
| DC-06 | 清空完备 | 清空后 3 表 0 行 + 徽章 unlocked=0 + 证书 certDate=0 + 权益记录为空（DF-05 修复后口径） |
