## 四、横屏还是竖屏（最容易翻车的一步）

录屏是 1440×2832 **竖屏**。如果成片保持竖屏，投到 16:9 的答辩投影上，画面只占中间一条，两侧大片黑边，观众看不清字。

**建议成片做 1920×1080 横屏**，版式：

```
┌──────────────────────────────────────────────┐
│                                              │
│   ┌────────┐   当前环节：AI 批量识别          │
│   │        │   ─────────────────            │
│   │ 手机   │   一次最多选 9 张                │
│   │ 录屏   │   逐张识别，确认后入库            │
│   │ 9:19.5 │                                │
│   │        │   ● 记录 → 计算 → 统计 → 积分    │
│   └────────┘   → AI → 同步 → 导出            │
│                                              │
└──────────────────────────────────────────────┘
```

- 左侧手机画面高度占 90%（约 972px），宽约 449px，加 12px 圆角 + 细边框，像真机
- 右侧放：环节标题、一句要点、底部七步进度指示器（当前步高亮）
- 背景用深色纯色或极淡渐变，别用花哨素材
- 好处：竖屏内容不变形、右侧信息区填补空白、进度条让评委随时知道讲到第几步

如果确定只做竖屏发布（手机端观看），就保持 1080×2340，但答辩时必须提前说明，或准备一版横屏。

## 五、制作流程（五步，按顺序做）

**1. 分段录屏（约 1 小时）**
不要一镜到底。按 10 个镜头分 10 次录，每次只做一段操作，开头结尾各多录 3 秒。
文件名 `s01.mp4` … `s10.mp4`，放在 `raw/` 目录。
好处：某一段失手只需重录那一段，不用重来。

**2. 配音（约 1 小时）**
对着第三节的表念，**分段录**，一个镜头一个文件，念错就重录这一段。
采样 48kHz、单声道、-6dB 峰值，房间挂厚衣物或被子吸音，离麦 15–20cm。
不要加背景音乐，配音轨保持干净。

**3. 粗剪（约 2 小时）**
先把配音轨按第二节的时间轴铺在时间线上，再往每条音轨下面填画面。
画面不够长就局部变速（0.8–1.5 倍），画面太长就切掉。
原则：**声音不动，画面迁就声音**。

**4. 包装（约 2 小时）**
关键数字做放大标注：1.08 kg、+10 积分、9 张、12.6 公里、16 篇。
转场统一用一种（推荐叠化 0.2s），别花哨。
BGM 选无鼓点的轻电子或钢琴，音量压到 -22dB 以下，人声一开口就不能被盖。

**5. 导出（20 分钟）**
H.264，1920×1080，30fps，码率 5–6 Mbps，音频 AAC 192kbps。
导出后完整看一遍，重点查：字幕错别字、数字与画面是否一致、有没有出现学校/团队信息。

## 六、录屏避坑

| 坑 | 处理 |
|---|---|
| 鼠标指针入镜 | scrcpy 加 `--no-cursor`，或用模拟器自带录屏 |
| 帧率不稳、拖动卡顿 | 码率降到 4 Mbps，关掉 DevEco 等占资源的程序 |
| 状态栏露出通知 | 提前开勿扰模式，录前清一次通知栏 |
| 录到 5 分钟一镜到底 | 不要，分段录，见第五节 |
| 竖屏直接投屏 | 见第四节，做成横屏版式 |

## 七、配音避坑

| 坑 | 处理 |
|---|---|
| 一口气念完 5 分钟 | 分段录，每段 20–45 秒，念错只重录一段 |
| 数字念得含糊 | 1.08 念"一点零八"，180 念"一百八十"，别吞音 |
| 语速越念越快 | 每句结尾刻意放慢，尤其是列举句 |
| 气口太明显 | 在逗号处换气，不在句子中间断 |
| 全程一个调 | 镜头 6、7 是加分项，语气可以扬起来；镜头 10 收尾降调 |
| 有回声 | 在衣柜前录，或被子挂起来，别在空旷房间 |
