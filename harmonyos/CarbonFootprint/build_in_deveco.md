# 构建步骤

当前 Hvigor 命令行构建失败，因为 DEVECO_SDK_HOME 环境变量配置不正确。

请在 DevEco Studio 中执行构建：

1. 打开 DevEco Studio
2. 打开项目：`D:\aaaa\CarbonFootprint`
3. 等待项目索引完成
4. 点击顶部菜单：**Build** > **Clean Project**
5. 再点击：**Build** > **Build Hap(s)/APP(s)** > **Build Hap(s)**
6. 查看底部 Build 窗口的输出
7. 如果有编译错误，把完整错误信息（从第一条 error 开始）复制发来
