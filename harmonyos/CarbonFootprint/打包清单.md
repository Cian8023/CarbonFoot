### F. 签名（不附带材料，用 DevEco 自动生成）

本项目**不包含**任何签名证书或密钥库。评委/开发者在自己机器上按下面两步即可：

```
File > Project Structure > Project > Signing Configs
  → 勾选「自动生成签名文件」→ 确定
```

DevEco 会在本机 `~/.ohos/config/` 生成 `default_CarbonFootprint_*.p12 / .p7b / .cer`，之后 Run / Build 都会自动签名。

> ⚠️ **打包前务必清空 `build-profile.json5` 里的 `signingConfigs`**（改成 `[]`）。
> 因为 DevEco 写入的密码是**本机加密的密文**，换一台机器解密必然失败，会导致评委打不开工程。
> 清空后对方点一次「自动生成签名文件」即可，不依赖任何账号或证书文件。
>
> ⚠️ 同一台设备上**不要混用两套签名**。换签名后首次安装必须先 `hdc uninstall`（**不要加 `-k`**）再装，否则报 `9568332 install sign info inconsistent`。

  CarbonFootprint/README.md \
  CarbonFootprint/碳足迹-版本迭代文档.md \
  CarbonFootprint/碳足迹-企业级测试文档.md \
  CarbonFootprint/测试执行报告-v5.0.0.md \

  --include="*.md"
