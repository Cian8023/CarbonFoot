## 三、必须清除的配置

### 1. `build-profile.json5` — 清空签名配置（关键）

**现状**：里面写死了本机证书路径与加密密码。

```json5
"signingConfigs": [
  {
    "name": "default",
    "type": "HarmonyOS",
    "material": {
      "certpath": "C:\\Users\\27544\\.ohos\\config\\default_CarbonFootprint_xxx.cer",
      "keyAlias": "debugKey",
      "keyPassword": "0000001BD45F9AEE3613DC207BE308E7...",
      "profile": "C:\\Users\\27544\\.ohos\\config\\default_CarbonFootprint_xxx.p7b",
      "storeFile": "C:\\Users\\27544\\.ohos\\config\\default_CarbonFootprint_xxx.p12",
      "storePassword": "0000001BEE0ED1C6F9BA8BB4BA98536..."
    }
  }
],
```

**问题**：
- 三个路径都指向 `C:\Users\27544\`，评委机器上没有这些文件
- 两个密码是 DevEco 用**本机密钥加密**的密文，换机器解不开

**改为**：

```json5
"signingConfigs": [],
```

**同时检查** `products` 里是否还有 `"signingConfig": "default"`，有则一并删除：

```json5
"products": [
  {
    "name": "default",
    "signingConfig": "default",   ← 删掉这一行
    ...
  }
]
```

**评委端操作**：DevEco → File → Project Structure → Signing Configs → 勾选「自动生成签名文件」→ OK，即可编译。

### 2. 其他需检查的位置

| 文件 | 检查项 | 处理 |
|---|---|---|
| `entry/build-profile.json5` | 是否含 `signingConfigs` | 一般无，确认即可 |
| `AppScope/app.json5` | `bundleName`、`vendor` | 保留 `com.carbon.footprint`；`vendor` 若写了自己名字要改 |
| `oh-package.json5` | `author` 字段 | 当前为空，保持空（匿名要求） |
| `entry/src/main/resources/base/element/string.json` | `app_name`、`vendor` | 确认无院校/团队字样 |
| `mock/server.js`、`sync/server.js` | 硬编码 IP | 确认是 `127.0.0.1` 或 `localhost`，不要留你的局域网 IP |

## 四、打包步骤

### 方式一：手动复制（稳妥）

```bash
# 1. 建目标目录
mkdir -p /d/提交包/CarbonFootprint

# 2. 复制根级配置与文档
cp build-profile.json5 hvigorfile.ts oh-package.json5 .gitignore README.md build_in_deveco.md \
   /d/提交包/CarbonFootprint/

# 3. 复制构建配置
cp -r hvigor /d/提交包/CarbonFootprint/

# 4. 复制应用资源
cp -r AppScope /d/提交包/CarbonFootprint/

# 5. 复制 entry 模块（排除 build 与 .test）
rsync -a --exclude='build/' --exclude='.test/' --exclude='oh_modules/' \
   entry /d/提交包/CarbonFootprint/

# 6. 复制本地服务
cp -r mock sync /d/提交包/CarbonFootprint/
rm -f /d/提交包/CarbonFootprint/sync/data.json \
      /d/提交包/CarbonFootprint/sync/data.bak.json

# 7. 复制材料
cp 碳足迹-全民绿色生活碳积分与减排指南-设计方案.docx \
   碳足迹-项目介绍.pptx 碳足迹-演示视频.mp4 \
   碳足迹-企业级测试文档.md 测试执行报告-v5.0.0.md \
   碳足迹-版本迭代文档.md 打包清单.md \
   /d/提交包/CarbonFootprint/
```

### 方式二：用 rar / 7z 排除法（更快）

```bash
# 在工程根目录执行，直接排除不需要的
7z a -r 提交包.rar . \
  -xr!build -xr!.hvigor -xr!.idea -xr!.git -xr!.test \
  -xr!oh_modules -xr!.workbuddy-ai \
  -xr!tools -xr!raw -xr!ppt -xr!output \
  -xr!local.properties \
  -xr!*.bak.mp4 -xr!sync/data.json
```

## 五、交付前自检

### 编译验证（必做）

```bash
# 1. 在干净环境打开工程（确认不依赖你本机的任何缓存）
# 2. DevEco 里勾选「自动生成签名文件」
# 3. 执行编译
hvigorw assembleHap --no-daemon
# 期望输出：BUILD SUCCESSFUL
```

若报 `00303116`：签名配置没清干净。
若报 `9568332`：证书不匹配，检查 `signingConfigs` 是否为空。

### 内容检查

- [ ] 包内无 `signingConfigs` 中的绝对路径（全文搜索 `C:\Users`）
- [ ] 包内无 `local.properties`
- [ ] 包内无 `.hvigor`、`build`、`oh_modules`、`.idea`
- [ ] 全文搜索「大学」「学院」「团队」「指导」无命中（匿名要求）
- [ ] `oh-package.json5` 的 `author` 为空
- [ ] 所有 `.md` 文档中的学校/团队信息已清除
- [ ] 体积在 5~15 MB 之间（小于 5 MB 可能漏文件，大于 15 MB 可能带了大文件）

### 体积预期

| 组成 | 大小 |
|---|---|
| 源代码（139 个文件） | ~1.5 MB |
| 设计方案 docx | 34 KB |
| PPT | 3.6 MB |
| 演示视频 | 5.8 MB |
| 三份 md 文档 | 165 KB |
| **合计** | **约 11 MB** |

> 压缩为 rar 后约 10 MB（视频与 PPT 已压缩，收益有限）。

## 六、命名与提交

赛题要求压缩包命名为「赛题序号 + 赛题名称 + XX学校团队名称」。

```
赛题二+全民绿色生活碳积分与减排指南+XXX学校XXX团队.rar
```

> 注意矛盾点：**压缩包文件名要求含学校团队名称**，但**材料内容要求匿名**。两者不冲突——文件名给组织方归档用，文档内文与视频画面不出现即可。
