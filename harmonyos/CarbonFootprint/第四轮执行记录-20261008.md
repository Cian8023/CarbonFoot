## 新发现缺陷汇总
- **DF-15（S2）**：首页周报卡"预选近7天"失效两场景（首次进历史页懒初始化+AppStorage同值写入不触发Watch）→ 已修复（History 改 @StorageLink 双向+@Watch 刷新）；回归 T56/T57 通过。
- **DF-16（S3）**：双碳科普列表"已读 x/16"统计从详情页返回后不刷新（Knowledge.ets 缺少 tick 监听）→ 已修复（加 @StorageLink('tick') @Watch('refresh')）。
- **DF-17（S2）**：AI 识别遇连接级异常（如 curl 重定向超限 CURLcode 47）时 HttpClient.postJson 直接抛错未被捕获，导致"识别失败"冒泡而非按承诺降级到离线演示 → 已修复（recognize() 内 try/catch 网络调用与 JSON 解析，统一走 demoGuess 降级）；回归验证：识别卡正确显示「离线演示」标签。
- **DF-18（S3）**：碳普惠权益列表兑换后库存"余 999"不刷新（ForEach key 仅用 b.id，新对象同 key 导致复用旧渲染节点，与 DF-13 同类根因）→ 已修复（key 改为 b.id + '_' + b.stock）。
