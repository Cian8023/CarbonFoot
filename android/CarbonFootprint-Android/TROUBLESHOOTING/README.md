## 新增文档规范

### 文件命名

```
<平台>-<问题简述>.md
```

示例：`ArkUI-X-Android白屏问题.md`、`Android沉浸式状态栏与顶部避让.md`、`Harmony-模拟器启动失败.md`

### 文档结构（参照已有文档）

1. **元信息表** —— 类型、项目、标题、日期、版本、严重程度、状态、关键词
2. **摘要（TL;DR）** —— 现象、根因、修复、启示，30 秒可读完
3. **环境信息** —— 设备、SDK、工具链、版本等可复现条件
4. **问题现象** —— 观察到的表现
5. **排查过程** —— 分阶段的完整时间线，含命令与真实日志，保留走过的弯路
6. **根本原因分析** —— 机制说明 + 证据（源码/日志）+ 根因结论表，建议配 Mermaid 图
7. **解决方案** —— 具体改动（diff）与操作步骤
8. **验证结果** —— 修复前后日志对照 + 状态检查表
9. **经验总结与避坑指南** —— 可复用的经验教训
10. **附录** —— 命令速查、关键文件清单、日志关键词对照表、参考资料

### 状态标记
